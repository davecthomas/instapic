# Instapic - Download a high res image from an Instagram image src tag

Instareel will download an mp4 file from a reel.

# Install

```bash
python3 -m venv venv
source venv/bin/activate
pip3 install -r requirements.txt
python3 instapic.py '<instagram img src tag>'
python3 instareel.py "https://www.instagram.com/reel/1234567/"
```
